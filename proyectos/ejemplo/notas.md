# Así se hace un vídeo en este taller (ejemplo)

Es el vídeo de ejemplo que viene con el taller. No está hecho para publicarse: sirve para comprobar que el motor
funciona en este ordenador y para ver cómo se escribe un vídeo.

- No tiene voz: los tiempos de `palabras.json` están puestos a mano. `node motor/voz.mjs ejemplo` la hace de verdad
  (cuesta céntimos) y los sustituye.
- No afirma datos: por eso `hechos.json` está vacío.
